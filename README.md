# Construction Site Hazard Reporting and Corrective Action Management System

## Project Overview

A web-based system designed to support hazard reporting, risk assessment, corrective-action management, and verification in building and road construction projects.

## Main Objective

To develop a centralized and traceable system that helps construction-site personnel report hazards, assess risks, assign corrective actions, monitor progress, and verify corrective measures before closing hazard reports.

## Target Construction Types

- Building construction
- Road construction

## System Users

- Worker
- Safety Officer
- Site Manager
- Administrator

## Core Workflow

1. Hazard reporting
2. Risk assessment
3. Corrective-action assignment
4. Corrective-action progress tracking
5. Independent verification
6. Hazard closure and reporting

## Planned Technology Stack

### Backend
